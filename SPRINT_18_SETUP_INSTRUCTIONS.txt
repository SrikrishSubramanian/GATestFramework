SECURITY & TOKEN MANAGEMENT
═══════════════════════════════════════════════════════════════════════════════

IMPORTANT - Never commit your token to git!

For temporary use (this session only):
  export JIRA_API_TOKEN="token"

For persistent use (recommended):
  1. Add to ~/.bashrc or ~/.zshrc:
     echo 'export JIRA_API_TOKEN="your-token"' >> ~/.bashrc
  2. Reload:
     source ~/.bashrc

For CI/CD pipelines:
  1. Add JIRA_API_TOKEN as a repository secret
  2. Use in pipeline: ${{ secrets.JIRA_API_TOKEN }}

Token rotation:
  1. Visit: https://id.atlassian.com/manage-profile/security/api-tokens
  2. Delete old token
  3. Create new one
  4. Update environment variable

FREQUENTLY ASKED QUESTIONS
═══════════════════════════════════════════════════════════════════════════════

Q: How long does it take?
A: ~2-5 minutes per ticket = ~1-2 hours total for 28 tickets

Q: Can I stop it midway?
A: Yes, press Ctrl+C. You can resume by running the command again.

Q: What if a ticket fails?
A: The script logs the error and continues to the next ticket.
   Check .claude/sprint-18-generation/generation-*.log for details.

Q: What batch size should I use?
A: Start with 3 (default). Increase to 5-6 if your system is fast.

Q: Can I run it on CI/CD?
A: Yes, set JIRA_API_TOKEN as a secret and run the Node.js script.

Q: What environments can I use?
A: local (default), dev, qa, uat, prod
   Example: node scripts/run-sprint-18-batch.js dev 3

For more FAQ, see: SPRINT_18_BATCH_GENERATION.md

TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

If you get an error, check these files:
  .claude/sprint-18-generation/generation-*.log  (detailed error logs)
  reports/sprint-18-summary-*.txt               (summary report)

Common issues:

  "JIRA_API_TOKEN not set"
    → Solution: export JIRA_API_TOKEN="your-token"

  "HTTP 401: Unauthorized"
    → Solution: Token is invalid. Get a new one.

  "Cannot find playwright"
    → Solution: npm install && npx playwright install

  "AEM not responding"
    → Solution: Start AEM or use env=dev

  "Generator takes forever"
    → Solution: Check if AEM is slow, or reduce batch size

For detailed troubleshooting, see: SPRINT_18_BATCH_GENERATION.md
